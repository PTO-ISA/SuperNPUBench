Out-of-place only; input/output must not overlap. Defaults:512 U16 elements per full Tile,4096 maximum plane elements,4PE. Local registers use CUBE_M32; GM tensors use ND. SharedTile footprint0.
The planner combines up to two trailing output axes if their product<=MaxPlaneElements. Otherwise it uses the last axis. If that axis exceeds the limit, it selects its largest divisor<=the limit. This preserves additive input offsets and allows reuse of static index tiles. Prime long axes may degenerate to one element per plane; correctness does not imply good performance for every shape.
Each plane is partitioned into full tiles, a remaining rectangle with32rows, and at most one short single-column tail. Partial rows have physical32rows; U16 physical columns round up to multiples of2. U32 index tiles use the same coordinate geometry. Padding offsets are zero.
All byte offsets are generated by C++ constexpr into static constant arrays, not Python. Indices load once perPE before the plane loop. PEs own plane numbers pe,pe+PeCount,... . Fewer planes than PEs leave some PEs idle. Runtime scalar arithmetic only maps each plane base; no per-element runtime index arithmetic.
Force-inline annotations keep Tile objects within the kernel; the current compiler's outlined transfer calls introduced invalid CUBE reloads during initial validation.
Supported full-tile parameters:32..512 elements, divisible by32. This bounds data tiles at1KiB and avoids the observed2KiB experiment deadlock. Larger tiles are not enabled by this interface.
